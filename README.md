# OficinaMecanicaSystem

Projeto acadêmico de uma aplicação para Oficina Mecânica.

## Tecnologias

- Frontend: React Native + Expo + TypeScript
- Backend: Node.js + Express
- Integração: API REST com `fetch`
- Estilização: NativeWind

## Estrutura

```text
OficinaMecanicaSystem/
├── System/
│   ├── Frontend/
│   └── Backend/
└── docs/
```
